# 동현파 v0.98 검증 기록

## 자동 검사

Node.js 20 환경에서 `npm test`로 회로·명령 검사 51개, 문서 검사 6개, 시각 모델·시간 검사 11개, 총 68개를 통과했다. 데이터 재생성 후 `npm run build`가 네트워크 의존성 설치 없이 실행된다.

- 원본 5,863행과 279개 이름 검증, 가공 연결과 원본의 대응 검사.
- 앞쪽/뒤쪽 입력 차이, 높은 세기 입력, MEC 관련 입력 계수 0, 출력 차단·복원, 활성도 유한 범위 검사.
- 같은 시드의 관측값 일치, 손 구분이 같은 입력의 신경 계산을 바꾸지 않음, 세기에 따른 밀림·과장 효과 크기 검사.
- 실제 동현랭 실행기로 예제 23개 실행. 09번의 손 순서는 1·2·1·2·1·2, 접촉은 6회였다. 연속기 09~22번의 접촉은 6회에서 10회로 늘어나며, 21·22번은 10회 접촉했다.
- 마지막 23번 빈 코드는 시작·끝 선언만 있고, 0초·0회 접촉·활성 및 충격 0이었다.
- 잽의 즉시 회수·스트레이트의 긴 밀기, 어퍼컷의 상승, 훅의 하방 곡선·버티기, 바디블로우와 큰 스윙, 모든 기술의 목표 접촉점 검사.
- 선충 길이 90%, 과장 반응의 필드 내 제한, 자동 Y축의 15% 여유·단조 확장·새 실행 초기화, ⅓ 속도 재생 상수 검사.
- 잘못된 시작 문장·명령·인수·손·세기·위치·시간, 빈 입력 큐, 무한 반복, 모의 시간 한도와 중단 검사.
- Markdown 원문 블록과 굵은 글씨, 라이선스 전문 보존, 위험 HTML 제거와 데이터 다운로드 안내 검사.

## 브라우저와 화면

v0.2에서 Chromium으로 예제 20개를 실제 선택·실행한 결과를 `browser-results.json`에 보존. v0.3은 동일 실행기에 대한 자동 전수 검사와 더불어, 8개 기술을 모두 포함하는 연속기·그래프 확대·새 실행 초기화·중단·문서·저장·공통 이동 메뉴를 브라우저에서 재검사한다.

1440px 데스크톱과 375px 모바일 뷰포트에서 밝은/어두운 화면 검사. 같은 페이지를 데스크톱→모바일→데스크톱으로 바꾸어 가로 넘침 여부와 화면 재계산 확인. 이 검사는 실제 iPhone/Safari 기기 검사가 아니다.

왼쪽의 작은 분홍 선충, 가운데의 작은 몸·큰 머리 소녀와 늘어난 팔·글러브 확인. v0.4에서는 픽셀아트 소녀의 기본 자세와 8개 기술의 준비·비행·접촉 장면을 밝은·어두운 화면에서 확대 확인. v0.5에서는 작아진 뿌까머리와 리본, 빨간 운동화, 오른쪽으로 옮긴 장면 배치 확인. v0.6에서는 동그란 뿌까머리와 작은 리본, H라인 미니스커트를 기본 자세와 펀치 장면에서 확인. v0.3에서 실험 최대 0.559에 대해 Y축이 0.80으로 확장되고 그래프 높이가 440px가 되는 것 확인. 이전의 0~0.10 고정 상한과 초과 삼각형 표시는 제거됐으며, 작은 신호와 큰 봉우리를 같은 원 단위로 표시한다.

추가로 확인한 흐름:

- `.dh` 저장 후 코드 열기로 다시 불러오기.
- 잘못된 코드의 오류 메시지와 정상 코드로 복구.
- Ctrl+Enter 실행, 실행 중 중단, 재실행.
- 관측 CSV 다운로드와 출처 메타데이터 포함.
- 모델 설명·데이터 계보·출처·라이선스 탭과 ODbL 전문 펼치기.
- 가공 데이터 JSON 다운로드, 279개 뉴런과 출처 정보 확인.
- 동현랭 안내 링크 실제 클릭 후 플레이그라운드 이동 확인.
- 세 글꼴의 로딩 완료, 검사 중 새 JavaScript 페이지 오류 없음.

## 오프라인 단일 HTML

별도 Chromium 컨텍스트의 네트워크를 끈 상태에서 `file://`로 완성 HTML 실행. 연속기 4회 접촉 완료, 내장 글꼴 로딩, 출처 문서 표시, 가공 데이터 JSON 다운로드가 작동했다.

이 검사는 일반 데스크톱 브라우저 실행을 대상으로 한다. 모바일 메신저·파일 앱의 자체 미리보기, 모든 운영체제·모든 브라우저에서의 실행을 보증하지 않는다.

## 과학적 검증 범위

검사 결과는 구현의 기능·일관성·재현성을 확인한 것이다. 실제 선충의 복싱 반응, 통증·손상, 유전자 발현, 막전위 또는 실측 발화율 예측의 검증이 아니다.

원 자료는 무방향·무가중치 3층 연결망이며, 앱은 문헌 기반 기능 제약과 자체 활성도 방정식을 추가한다. 원 데이터 설명은 [CoMuNeLab 저장소](https://github.com/CoMuNeLab/C-elegans-Multiplex-Connectome), 전후 촉각 회로 근거는 [Schafer의 리뷰](https://pmc.ncbi.nlm.nih.gov/articles/PMC4281349/)에서 확인할 수 있다.
