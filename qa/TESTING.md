# 동현파 v0.2 검증 기록

## 자동 검사

Node.js 20 환경에서 `npm test`로 회로·명령 검사 47개, 문서 검사 6개, 시각 모델 검사 6개, 총 59개를 통과했다. 데이터 재생성 후 `npm run build`가 네트워크 의존성 설치 없이 실행된다.

- 원본 5,863행과 279개 이름을 검증하고 가공 연결과 원본의 대응을 검사했다.
- 앞쪽/뒤쪽 입력 차이, 높은 세기 입력, MEC 관련 입력 계수 0, 출력 차단·복원, 활성도 유한 범위를 검사했다.
- 같은 시드의 관측값 일치, 손 구분이 같은 입력의 신경 계산을 바꾸지 않음, 세기에 따른 밀림·과장 효과 크기를 검사했다.
- 실제 동현랭 실행기로 예제 20개를 모두 실행했다. 09번의 손 순서는 1·2·1·2, 접촉은 4회였으며 19번은 8회 접촉했다.
- 마지막 20번 빈 코드는 시작·끝 선언만 있고, 0초·0회 접촉·활성 및 충격 0이었다.
- 잽의 수평 경로, 어퍼컷의 상승 경로, 훅의 곡선 경로와 모든 기술의 목표 접촉점을 검사했다.
- 선충 길이 90%, 과장 반응의 필드 내 제한, 계산값을 바꾸지 않는 그래프 확대·활성도 기반 빛 표시를 검사했다.
- 잘못된 시작 문장·명령·인수·손·세기·위치·시간, 빈 입력 큐, 무한 반복, 모의 시간 한도와 중단을 검사했다.
- Markdown 원문 블록과 굵은 글씨, 라이선스 전문 보존, 위험 HTML 제거와 데이터 다운로드 안내를 검사했다.

## 브라우저와 화면

Chromium에서 분리 파일 웹판의 예제 20개를 실제 선택·실행해 모두 완료되는 것을 확인했다. `browser-results.json`에는 예제별 시간·접촉 횟수와 완료 상태가 들어 있다.

1440px 데스크톱과 375px 모바일 뷰포트에서 밝은/어두운 화면을 검사했다. 같은 페이지를 데스크톱→모바일→데스크톱으로 바꾸어 가로 넘침 여부와 화면 재계산을 확인했다. 이 검사는 실제 iPhone/Safari 기기 검사가 아니다.

왼쪽의 작은 분홍 선충, 가운데의 작은 몸·큰 머리 소녀와 늘어난 팔·글러브를 확인했다. 잽의 수평 전완과 어퍼컷의 상승 방향을 캡처하고, 감각·회로의 색깔 빛과 반짝임, 확대 그래프의 0~0.10 축 및 초과 삼각형·실제 최대값 표시를 검사했다.

추가로 다음 흐름을 확인했다.

- `.dh` 저장 후 코드 열기로 다시 불러오기.
- 잘못된 코드의 오류 메시지와 정상 코드로 복구.
- Ctrl+Enter 실행, 실행 중 중단, 재실행.
- 관측 CSV 다운로드와 출처 메타데이터 포함.
- 모델 설명·데이터 계보·출처·라이선스 탭과 ODbL 전문 펼치기.
- 가공 데이터 JSON 다운로드, 279개 뉴런과 출처 정보 확인.
- 동현랭 안내 링크를 실제 클릭해 플레이그라운드로 이동.
- 세 글꼴의 로딩 완료, 검사 중 새 JavaScript 페이지 오류 없음.

## 오프라인 단일 HTML

별도 Chromium 컨텍스트의 네트워크를 끈 상태에서 `file://`로 완성 HTML을 열었다. 연속기 4회 접촉 완료, 내장 글꼴 로딩, 출처 문서 표시, 가공 데이터 JSON 다운로드가 작동했다.

이 검사는 일반 데스크톱 브라우저 실행을 대상으로 한다. 모바일 메신저·파일 앱의 자체 미리보기, 모든 운영체제·모든 브라우저에서의 실행을 보증하지 않는다.

## 과학적 검증 범위

검사 결과는 구현의 기능·일관성·재현성을 확인한 것이다. 실제 선충의 복싱 반응, 통증·손상, 유전자 발현, 막전위 또는 실측 발화율 예측의 검증이 아니다.

원 자료는 무방향·무가중치 3층 연결망이며, 앱은 문헌 기반 기능 제약과 자체 활성도 방정식을 추가한다. 원 데이터 설명은 [CoMuNeLab 저장소](https://github.com/CoMuNeLab/C-elegans-Multiplex-Connectome), 전후 촉각 회로 근거는 [Schafer의 리뷰](https://pmc.ncbi.nlm.nih.gov/articles/PMC4281349/)에서 확인할 수 있다.
