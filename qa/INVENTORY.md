# 동현파 v0.2 검사 범위

- 동현초와 같은 색·글꼴·2열 구성. 1280/1440px와 375px, 밝은/어두운 화면에서 확인한다.
- 640×480 비율 필드에 왼쪽 세로 선충, 가운데 픽셀 양쪽 머리묶음·원피스·글러브 소녀가 보인다.
- 19개 실행 예제와 마지막 빈 코드를 실제 선택·실행한다. 접촉 수·종료 상태·예제별 회로 반응을 확인한다.
- 작은 소녀와 큰 머리·늘어난 팔·확대 글러브, 분홍 선충 90% 크기, 10배 표시 이득·회로 반짝임과 Y축 상단 초과 표시를 확인한다.
- 오른손 잽과 왼손 어퍼컷, 연속기의 접촉 순간·충격 후 밀림·구김을 캡처한다.
- 실행 중 편집/예제 선택 잠금, 중단, 재실행, 잘못된 코드, 코드 열기/저장, CSV와 데이터 JSON 저장을 확인한다.
- 조작 규약, 모델 설명, 데이터 계보, 전체 출처, 라이선스와 외부 링크를 확인한다.
- 단일 HTML을 file URL로 열고 네트워크 없이 실행·문서·데이터 다운로드를 확인한다.
- 모델 검사는 생물학적 예측 검증과 구별한다. 앞/뒤 차이·차단·입력 계수·결정적 재현성과 유한 범위를 검사한다.
- 추가 탐색: 실행 중 탭 전환 및 화면 크기 변경, 빈 입력 후 복구, 긴 코드 내부 스크롤과 모바일 문서 표를 확인한다.
