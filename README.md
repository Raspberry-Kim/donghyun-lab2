# 동현파™ · donghyun-lab2

동현파의 동현랭 소녀는 동현랭만 알아듣는다. 동현랭은 한국어로 쓰는 난해한 프로그래밍 언어다. 예제를 골라 실행하면 소녀가 분홍 선충에게 잽과 어퍼컷을 날리고, 선충은 맞은 자리에 따라 다르게 꿈틀거린다. 그 사이 선충의 촉각 회로에서 어떤 신호가 켜지는지 함께 볼 수 있다.

필드 왼쪽에는 선충이 길게 서 있고, 가운데에는 양쪽으로 머리를 묶고 원피스에 권투 글러브를 낀 픽셀게임풍 소녀가 있다. 오른손 잽, 왼손 어퍼컷, 스트레이트를 동현랭으로 이어 쓰면 접촉과 신경 계산, 밀려나는 몸과 꿈틀거림이 한 시간축 위에서 펼쳐진다.

- **[동현파 플레이그라운드에서 바로 실행하기](https://raspberry-kim.github.io/donghyun-lab2/)**
- **[동현랭 플레이그라운드](https://raspberry-kim.github.io/donghyun-lang/)**: 소녀가 알아듣는 언어의 문법과 예제를 볼 수 있다.
- **[동현랭 GitHub](https://github.com/Raspberry-Kim/donghyun-lang)**: 언어의 실행기 소스와 명세가 있다.
- **[동현초™ · 초파리 회로실험실](https://raspberry-kim.github.io/donghyun-lab1/)**: 같은 디자인으로 만든 첫 번째 실험실이다.
- **[동현빌™ · 마을 유행 실험실](https://raspberry-kim.github.io/donghyun-lab3/)**: 실제로 기록된 469명의 만남 위에서 홍역·백일해·인플루엔자의 유행과 접종을 실험하는 세 번째 실험실이다.

네 사이트는 상단의 **동현의 작은 실험들** 메뉴로 이어져 있다. 지금 보고 있는 곳은 노란색으로 표시된다.

## 시작하기

설치할 것은 없다. 동현랭을 몰라도 준비된 예제를 고르고 실행해 보면 된다.

1. **[동현파 플레이그라운드](https://raspberry-kim.github.io/donghyun-lab2/)**를 연다.
2. 예제를 고른다. 처음이라면 **09 · 연속기 / 오른잽·왼어퍼**나 **10 · 원투 / 잽 → 스트레이트**가 좋다.
3. **코드 실행**을 누르고 주먹이 지나가는 길과 선충의 반응을 지켜본다. macOS에서는 Command+Enter, Windows나 Linux에서는 Ctrl+Enter로도 실행된다.
4. 반짝이는 감각·운동 회로, 활성 그래프, 기록을 살펴본다. 도중에 멈추고 싶으면 **오겡끼데스까**를 누르면 된다.
5. 다른 예제를 돌려 보거나 코드를 고쳐 보자. 코드는 `.dh`로, 관측 결과는 CSV로 저장할 수 있다. **20 · 빈 코드 / 직접 작성**에서 나만의 연속기를 짜 볼 수도 있다.

공격 버튼이나 방향키, 드래그 조작은 없다. **실험을 움직이는 명령은 모두 동현랭 코드에서만 나온다.** 예제를 고르거나 코드를 고치기만 해서는 시간이 흐르지 않고, 실행할 때마다 새 실험이 처음부터 시작된다.

회로가 어떻게 돌아가는지 궁금하다면 **모델과 출처** 탭을 열어 보자. 모델 설명, 데이터 계보, 전체 출처, 이용 안내, 글꼴과 코드 라이선스를 모두 그 안에서 읽을 수 있다.

## 화면에서 볼 수 있는 것

작은 몸에 머리가 큰 소녀가 팔만 쭉 늘려 주먹을 뻗고, 닿는 순간 글러브가 커진다. 선충은 옅은 분홍색이고, 활성화된 회로는 색색의 빛과 반짝임으로 드러난다. 움직임이 잘 보이도록 몸과 빛의 반응은 10배로 키워 보여 주지만, 계산값과 CSV에 담기는 숫자는 그대로다.

기술마다 동작이 다르다. 잽은 찌르고 바로 거두고, 스트레이트는 곧게 깊숙이 밀어 넣는다. 어퍼컷은 아래에서 위로 올라오고, 훅은 몸통을 향해 아래로 휘어 들어간다. 바디블로우는 낮고 짧게, 스윙은 크게 원을 그린다.

선충이 출렁이는 모습을 충분히 볼 수 있도록 전체를 ⅓ 속도로 재생한다. 그래서 다음 주먹이 오기까지 지켜볼 시간도 세 배가 된다. 화면의 초와 CSV는 원래의 모의 시간을 따른다.

신경 활성 그래프는 데스크톱에서 440px, 모바일에서 340px 높이로 넉넉하게 보여 준다. 세로축은 실험 중 가장 큰 값보다 15% 이상 여유를 두고 자동으로 늘어나서 봉우리가 잘리지 않는다. 한 번 늘어난 축은 같은 실행 안에서는 다시 줄어들지 않는다.

## 공개 연결망을 움직이는 장면으로

[CoMuNeLab 공개 자료](https://github.com/CoMuNeLab/C-elegans-Multiplex-Connectome)에 담긴 279개 뉴런과 세 가지 연결 층을 사용했다. 원본 기록 5,863개를, 원 자료가 밝힌 대로 방향과 가중치가 없는 연결로 정리하면 **층별 연결 3,108개**가 된다. 뉴런 이름, 원본 파일, 가공한 데이터, 변환 코드를 모두 저장소에 남겨 두었다.

연결망만으로는 선충이 어떻게 반응할지가 정해지지 않는다. 그래서 [촉각 회로 문헌](https://pmc.ncbi.nlm.nih.gov/articles/PMC4281349/)을 바탕으로, 원래 연결이 있는 뉴런 쌍에 기능적인 제약을 더했다. 머리 쪽을 건드리면 뒤로 물러나고, 꼬리 쪽을 건드리면 앞으로 나아가려는 경향이다. 화면의 값은 실제로 잰 발화율이 아니라 **단위 없는 모델 활성도(a.u.)**다.

유전체 서열을 시뮬레이션하는 프로젝트는 아니다. 유전자 발현, 발생, 몸 전체의 생리, 통증, 신경 손상, 실제로 맞았을 때의 반응은 계산하지 않는다. 밀려남, 찌그러짐, 먼지, 구김, 별 표시는 접촉 세기에 맞춰 만화처럼 과장한 효과일 뿐 신경 손상을 나타내지 않는다.

## 인터넷 없이 쓰기

저장소의 `index.html`을 내려받아 브라우저로 열면 오프라인에서도 그대로 실행된다. 코드와 회로 데이터, 글꼴, 예제, 출처와 라이선스가 모두 이 파일 하나에 들어 있다.

휴대폰의 파일 미리보기 기능에서는 스크립트가 돌지 않을 때가 있다. 그럴 때는 브라우저에서 [동현파 플레이그라운드](https://raspberry-kim.github.io/donghyun-lab2/)를 열면 된다. 외부 논문이나 동현랭 사이트로 가는 링크는 인터넷이 있어야 열린다.

## 직접 고쳐 보고 싶다면

웹에서 실험만 할 때는 이 부분을 건너뛰어도 된다.

```text
index.html             완성된 단일 HTML, GitHub Pages 진입점
src/                   동현랭 실행기·회로·워커·픽셀 캐릭터·화면 코드
data/connectome.json   가공한 279개 뉴런 연결망, ODbL 1.0
data/raw/              원본 자료 파일 3개
data/SOURCE.md         원 데이터 저장소의 설명
tools/build-connectome.cjs  검증·번호 재부여·중복 제거 도구
examples/              동현랭 예제 20개
fonts/                 동현초와 같은 내장 글꼴
licenses/              원 라이선스 전문
vendor/marked.cjs      빌드용 Markdown 변환기
render-docs.cjs        출처 문서를 HTML로 바꿔 앱에 넣는 도구
build.cjs              웹판·단일 파일·예제 빌드
qa/                    회로·명령·문서 시험
SHA256SUMS.txt         배포 파일의 체크섬
```

Node.js 18 이상에서 아래 명령을 실행하면 된다. 필요한 도구가 저장소에 들어 있어서 `npm install`은 하지 않아도 된다.

```sh
npm run data
npm test
npm run build
```

`src/`나 Markdown 문서를 고친 뒤 빌드하면 루트의 `index.html`, `동현파-v0.4.html`, 분리 파일판 `dist/`가 새로 만들어진다. 생성된 HTML을 직접 고치면 다음 빌드에서 덮어써지니, 원본을 고치는 편이 좋다.

## 출처와 이용 조건

**앱 코드와 연결 데이터는 라이선스가 다르다.** 동현파의 코드와 그림은 MIT, 연결 데이터와 가공한 DB는 ODbL 1.0, DB에 담긴 개별 내용은 DbCL 1.0, 글꼴은 SIL OFL을 따른다. Marked와 동현랭 실행기의 원 고지도 함께 남겨 두었다.

데이터가 들어 있는 완성 HTML을 다시 배포한다면 출처와 라이선스 안내, 그리고 가공한 DB를 받을 수 있는 방법을 그대로 남겨 주길 바란다. 앱의 ‘모델과 출처 → 모델 설명’에서 가공 데이터 JSON을 내려받을 수 있고, 저장소에는 원본과 가공본, 변환 도구가 함께 들어 있다. 자세한 조건은 [LICENSE](LICENSE), [CREDITS.md](CREDITS.md), [ODbL 원문](https://opendatacommons.org/licenses/odbl/1-0/)에 있다.

연구 논문의 그림이나 기존 만화 캐릭터를 따라 그리지 않았다. 소녀와 선충은 이 프로젝트를 위해 새로 그렸고, 공개 데이터와 연구진의 기여는 [데이터 계보](PROVENANCE.md)에 따로 적어 두었다.

## 만든 사람

본업은 백신학·감염학, 여기서는 작은 신경계에 말을 건다. 인하대학교 의과대학에서 백신학과 감염학을 연구하는 김동현이 취미로 만들었다. 동현초에 이어 동현파에서도, 직접 만든 동현랭으로 공개된 신경 연결망을 실험해 볼 수 있는 장면으로 옮겨 보고 싶었다.
