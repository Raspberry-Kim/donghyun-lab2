# 동현파™ · donghyun-lab2

동현랭은 난해한 프로그래밍 언어로 동현파의 동현랭 소녀는 동현랭만 알아듣는다. 예제를 골라 실행하고, 글러브의 접촉에 따라 달라지는 선충의 움직임과 신경 활성을 관찰하는 독립 촉각 회로실험실이다.

필드 왼쪽에는 길게 선 선충이, 가운데에는 양쪽 머리묶음과 원피스·권투 글러브 차림의 픽셀게임풍 소녀가 있다. 오른손 잽, 왼손 어퍼컷, 스트레이트를 동현랭으로 이어 쓰면 접촉과 신경 계산, 밀림과 꿈틀거림이 같은 시간축에서 진행된다.

- **[동현파 플레이그라운드 · 바로 실행하기](https://raspberry-kim.github.io/donghyun-lab2/)**: 선충 실험실을 열고 연속기 예제를 실행해 보자.
- **[동현랭 플레이그라운드 · 언어 알아보기](https://raspberry-kim.github.io/donghyun-lang/)**: 동현파가 알아듣는 동현랭의 문법과 예제를 살펴보자.
- **[동현랭 GitHub · 실행기와 언어 명세](https://github.com/Raspberry-Kim/donghyun-lang)**: 언어의 소스 코드와 명세를 확인한다.
- **[동현초 플레이그라운드](https://raspberry-kim.github.io/donghyun-lab1/)**: 같은 디자인의 첫 번째 초파리 회로실험실이다.

## 시작하기

파일을 내려받거나 프로그램을 설치할 필요 없이 웹에서 시작할 수 있다. 동현랭을 처음 접해도 준비된 예제를 선택해 실행하면 된다.

1. **[동현파 플레이그라운드 열기](https://raspberry-kim.github.io/donghyun-lab2/)**를 누른다.
2. 예제를 선택한다. 처음에는 **09 · 연속기 / 오른잽·왼어퍼** 또는 **10 · 원투 / 잽 → 스트레이트**를 권장한다.
3. **코드 실행**을 누르고 타격 궤적과 선충의 반응을 관찰한다. macOS는 Command+Enter, Windows/Linux는 Ctrl+Enter로도 실행한다.
4. 반짝이는 감각·운동 회로와 활성 그래프·기록을 살펴본다. 중단하려면 **오겡끼데스까**를 누른다.
5. 다른 예제를 실행하거나 코드를 바꾼다. 코드는 `.dh`, 관측 결과는 CSV로 저장하며, **20 · 빈 코드 / 직접 작성**에서 나만의 연속기를 쓸 수 있다.

공격 버튼·방향키·드래그 조작은 없다. **실험 상태를 바꾸는 모든 명령은 동현랭 출력에서만 나온다.** 예제 선택과 코드 편집만으로는 시간이 흐르지 않으며, 매 실행은 새 실험으로 시작한다.

회로의 원리와 근거가 궁금하면 **모델과 출처** 탭을 연다. 그 안의 **모델 설명·데이터 계보·전체 출처·이용 안내·글꼴·코드 라이선스** 메뉴에서 설명과 원문 고지를 읽을 수 있다.

v0.2에서는 작은 몸과 큰 머리의 소녀가 팔만 길게 늘려 타격하고, 접촉 때 글러브가 커진다. 선충은 옅은 분홍색이며, 활성화된 회로는 색깔 있는 빛과 반짝임으로 강조된다. 움직임과 활성 표시를 10배 확대하되 계산값·CSV는 그대로이며, 그래프의 0~0.10 a.u. 범위 초과는 삼각형과 실제 최대값으로 알린다.

## 공개 연결망을 움직이는 장면으로

[CoMuNeLab 공개 자료](https://github.com/CoMuNeLab/C-elegans-Multiplex-Connectome)의 뉴런 279개와 세 가지 연결 층을 사용했다. 5,863개 원본 기록을 원 자료의 무방향·무가중치 선언에 따라 정리하면 **층별 연결 3,108개**가 된다. 뉴런 이름·원본 파일·가공 데이터·변환 코드를 모두 보존했다.

이 연결망만으로 생리적 반응이 저절로 결정되지는 않는다. 동현파는 [촉각 회로 문헌](https://pmc.ncbi.nlm.nih.gov/articles/PMC4281349/)을 바탕으로, 원 연결이 있는 뉴런 쌍에 앞쪽 촉각의 후진 편향과 뒤쪽 촉각의 전진 편향을 표현하는 기능적 제약을 추가한다. 화면의 값은 실측 발화율이 아니라 **단위 없는 모델 활성도(a.u.)**다.

유전체 서열을 시뮬레이션하는 프로젝트는 아니다. 유전자 발현·발생·전신 생리·통증·신경 손상·실제 복싱 반응은 계산하지 않는다. 밀림·찌그러짐·먼지·구김·별 표시는 접촉 강도에 따른 만화적 과장 효과이며 신경 손상 지표가 아니다.

## 인터넷 없이 사용하기

저장소의 `index.html`을 내려받아 브라우저로 연다. 코드·회로 데이터·글꼴·예제·출처·라이선스가 한 파일에 들어 있어 별도 설치나 서버 없이 실행할 수 있다.

일부 모바일 파일 미리보기에서는 스크립트가 실행되지 않을 수 있다. 그런 경우에는 [동현파 플레이그라운드](https://raspberry-kim.github.io/donghyun-lab2/)를 브라우저에서 연다. 외부 문헌과 동현랭 사이트를 여는 데에는 인터넷이 필요하다.

## 파일 구성과 수정

```text
index.html             완성된 단일 HTML / GitHub Pages 진입점
src/                   동현랭 실행기·회로·워커·픽셀 캐릭터·화면 코드
data/connectome.json   가공한 279뉴런 연결망, ODbL 1.0
data/raw/              원본 3개 자료 파일
data/SOURCE.md         원 데이터 저장소의 설명
tools/build-connectome.cjs  검증·재색인·중복 제거 도구
examples/              동현랭 예제 20개
fonts/                 동현초와 같은 내장 글꼴
licenses/              원 라이선스 전문
vendor/marked.cjs      빌드용 Markdown 변환기
render-docs.cjs        출처 문서를 HTML로 통합하는 도구
build.cjs              웹판·단일 파일·예제 빌드
qa/                    회로·명령·문서 검사
```

Node.js 18 이상에서 아래 명령으로 재현할 수 있다. 빌드용 도구도 저장소에 들어 있어 `npm install`은 필요 없다.

```sh
npm run data
npm test
npm run build
```

`src/`와 Markdown 원문을 수정한 뒤 빌드하면 루트 `index.html`, `동현파-v0.2.html`, 분리 파일 웹판 `dist/`가 만들어진다. 생성된 HTML만 수정하면 다음 빌드에서 덮어써지므로 원본도 함께 수정한다. 게시 절차는 [GITHUB-SETUP.md](GITHUB-SETUP.md)에 있다.

## 출처와 이용 조건

**앱 코드와 연결 데이터의 라이선스는 다르다.** 자체 코드·그림은 MIT, 연결 데이터와 가공 DB는 ODbL 1.0 및 개별 내용의 DbCL 1.0, 글꼴은 SIL OFL을 따른다. Marked와 동현랭 실행기의 원 고지도 보존했다.

데이터를 포함하는 완성 HTML을 재배포할 때에는 출처·라이선스 안내와 가공 DB 접근 수단을 유지해야 한다. 앱의 ‘모델과 출처 → 모델 설명’에서 가공 데이터 JSON을 내려받을 수 있고, 저장소에는 원본·가공본·변환 도구가 함께 들어 있다. 자세한 조건은 [LICENSE](LICENSE), [CREDITS.md](CREDITS.md), [ODbL 원문](https://opendatacommons.org/licenses/odbl/1-0/)을 확인한다.

연구 논문의 그림이나 기존 만화 캐릭터 이미지를 복제하지 않았다. 소녀와 선충은 이 프로젝트에서 그린 원본이며, 공개 데이터와 연구진의 기여는 [데이터 계보](PROVENANCE.md)에 별도로 기록한다.

## 만든 사람

본업은 백신학·감염학, 여기서는 작은 신경계에 말을 건다. 인하대학교 의과대학 김동현 교수는 취미로 만든 동현랭을 통해, 동현초에 이어 동현파에서도 공개 신경 연결망을 실험 가능한 장면으로 옮긴다.
